# Работа с сайтом Express Today и GitHub

GitHub хранит историю проекта; сервер `/opt/hephaestus/app` — рабочая копия, из которой сейчас собирается сайт. Автоматического двустороннего копирования нет.

## Правки непосредственно на сервере

1. Перед изменением файлов выполнить `/opt/hephaestus/backup.sh`.
2. Проверить, что в GitHub не появились новые коммиты и нет чужих незакоммиченных изменений. При расхождении не делать `git reset --hard` и не перезаписывать файлы: сначала согласовать изменения.
3. Изменить файлы, проверить `npm run lint` и `npm run build`, собрать контейнер и проверить сайт.
4. Зафиксировать изменение в Git и отправить в GitHub как можно скорее, чтобы внешняя разработка шла от свежей версии.

## Разработка вне сервера

1. Перед началом скачать свежую ветку `main` из GitHub; работать в отдельной ветке и открыть pull request.
2. Перед объединением сверить изменения с сервером. Если сервер менялся после создания ветки, сначала объединить изменения и устранить конфликты.
3. Перед развертыванием сделать серверный бэкап; выполнять только контролируемое обновление, сборку и проверку сайта.

Файл `.env` содержит рабочие секреты: он хранится только на сервере и не отправляется в Git. В `.env.example` допустимы только заглушки. Не добавляйте токены и пароли в исходники или браузерный JavaScript.
